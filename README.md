# lp-goodbe-alto-ipiranga

Landing page da unidade **GoodBe Alto do Ipiranga** (Ipiranga, São Paulo/SP).
HTML único portátil (fotos e logos embutidos em base64), servido por nginx:alpine.
Mesmo design/template aprovado da Altino Arantes (clone exato, só troca o conteúdo da unidade).

- Deploy: Easypanel Server 1, projeto `site`, serviço `lp-goodbe-alto-ipiranga` (build por Dockerfile, autoDeploy).
